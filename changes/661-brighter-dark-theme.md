- **The dark theme is easier to read in bright rooms.** Dark mode now uses a dimmed cool slate instead of near-black, with distinct tones for the sidebar, the workbench, the transcript, cards and menus. Secondary text, timings and placeholders are brighter, and buttons and fields have visible outlines. The keyboard focus outline is solid amber. Code blocks, diffs, the file viewer and the terminal sit on the same slate surfaces. Diff and file views now use the code-block colour scheme, which keeps comments readable. The amber accent, status colours and the light theme are unchanged.
